# ZenTerm 优化计划

本文记录当前 `main` 分支的优化计划。项目功能链路和测试状态健康，但需要优先收紧工程边界、类型契约和高风险文件操作。

## 本轮落地项

1. **修正前后端 API 类型契约**
   - `InitializeVaultWithPreferences`、`UnlockWithPreferences`、`ChangeMasterPassword` 在 Go 端只返回错误，前端应声明为 `Promise<void>`。
   - `GenerateCredential`、`ImportCredential` 在 Go 端返回凭据 ID，前端应声明为 `Promise<string>`。

2. **固定 Go 测试入口**
   - 避免 `go test ./...` 扫入 `frontend/node_modules` 中第三方包。
   - 增加项目级测试命令，使用 `go test . ./internal/...`。

3. **优化会话记录读取**
   - 分块写入已经实现，读取时仍有字符串反复拼接。
   - 改为 `strings.Builder`，降低长日志读取时的内存复制成本。

4. **强化本地删除保护**
   - 本地 SFTP 面板支持删除文件和目录，后端需要阻止删除根目录、用户家目录等危险路径。
   - 保留正常目录内文件操作能力。

5. **WebDAV 拉取前自动备份**
   - `PullWebDAVSync` 会导入远端快照并替换本地可同步数据。
   - 导入前创建 `backups/config-*.zen`，降低远端快照异常或误操作风险。

## 后续拆分项

1. **拆分 `internal/db/store.go`**
   - 当前文件包含 Vault、Host、Credential、SessionLog、Transcript、WindowState、SyncSnapshot 等逻辑。
   - 建议拆为：
     - `store.go`
     - `store_vault.go`
     - `store_hosts.go`
     - `store_credentials.go`
     - `store_session_logs.go`
     - `store_transcripts.go`
     - `store_window.go`
     - `store_sync.go`

2. **拆分 SFTP 前端样式和控制器**
   - `frontend/src/styles/sftp.css` 仍然过大。
   - `SftpWorkspace.tsx` 可继续拆出对话框控制器、右键菜单控制器和主机切换器。

3. **Vault 参数版本化**
   - Argon2 参数目前固定在代码里。
   - 后续应写入版本信息，为升级密钥派生成本留出迁移路径。

4. **用应用内弹窗替代 `window.confirm`**
   - SSH config 自动导入提示目前使用浏览器原生确认框。
   - 后续应替换为统一的应用内 modal。
